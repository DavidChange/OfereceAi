# Como contribuir com o OfereceAí

Obrigado pelo interesse. O **OfereceAí 3.0** é um **projeto experimental e educacional**, usado para demonstrar o desenvolvimento de um MVP de marketplace inverso com auxílio de IA. **Não é um serviço comercial em operação.**

## Sugestões são bem-vindas

Você pode abrir uma **Issue** para propor melhorias de interface, acessibilidade, documentação, experiência dos perfis demonstrativos ou qualidade do código.

Para facilitar a análise, inclua:

1. Qual tela ou fluxo está envolvido.
2. O que você observou e qual comportamento esperava.
3. Como reproduzir o problema, quando aplicável.
4. Uma captura de tela **sem dados pessoais**, se ajudar.

## Propostas de código

Pull requests podem ser discutidas e revisadas pelo autor. Antes de propor mudanças maiores, abra uma Issue descrevendo a ideia. Procure manter alterações pequenas, documentar o que mudou e testar localmente os fluxos afetados.

Para executar o MVP, abra `site/index.html` em um navegador moderno; não há dependências para instalar. Consulte o [README](./README.md).

### Importante sobre direitos e licença

**Ainda não existe uma licença de software definida.** O repositório público não concede automaticamente permissão geral para copiar, redistribuir ou reutilizar o código. A intenção de receber contribuições não resolve, por si só, as condições legais de seu uso. Para qualquer uso ou contribuição que dependa dessas permissões, converse com o autor previamente.

## Escopo do projeto

O foco atual é **documentar o aprendizado e aprimorar uma demonstração local**. Propostas de backend, pagamentos e integrações de produção podem ser discutidas como ideias, mas não fazem parte dos objetivos assumidos para esta versão.
